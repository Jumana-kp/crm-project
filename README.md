# CRM - Customer Relationship Management System

A full-stack Customer Relationship Management (CRM) application built with Next.js, TypeScript, Django REST Framework, and PostgreSQL. The system helps manage customer-related business activities through a web interface and REST API.

## Project Structure

```text
crm-project/
├── crm-frontend/
├── crm-backend/
├── README.md
└── .gitignore
```

## Technologies Used

**Frontend**
- Next.js
- React
- TypeScript
- Redux Toolkit
- Axios
- Material UI (MUI)
- Recharts

**Backend**
- Python
- Django
- Django REST Framework
- PostgreSQL
- Role-based access control

## Features

- Customer and company management
- Role-based access and permissions
- REST API integration
- Frontend and backend separation
- Data visualization and dashboard interface

## Setup

The frontend and backend are maintained in separate folders.

- **Frontend:** Open `crm-frontend` and follow its `README.md` and setup instructions.
- **Backend:** Open `crm-backend` and follow its `requirements.txt` and project setup instructions.

Configure environment variables locally before running the application. Never commit secret keys, database passwords, or `.env` files.
